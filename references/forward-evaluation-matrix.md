# Forward Evaluation Matrix

Use this only when evaluating or evolving `skill-godot`, not as routine project guidance.

Maintain one blind scenario per materially distinct contract and several deliberate hybrids. Give the builder only the user brief, installed skill and isolated workspace. Keep expected failures, proposed fixes and prior reviewer verdicts out of the build prompt. A separate context reviews raw target-build artifacts and uncoached traces.

Minimum suite: 2D, 3D third-person, fixed isometric, fixed/high-angle 3D district composition, architectural material direction and action camera, 2.5D, procedural roguelike, strategy/simulation, vehicle/racing, shooter/action, narrative, local multiplayer, online/extraction, mobile native, localized release, large-world streaming, replay and runtime authoring. Hybrid scenarios should include shooter+extraction+progression, high-angle district+action/extraction, procedural+strategy+save, narrative+localization, and mobile+store+liveops. The high-angle negative fixture must include a fully material-covered district whose random flood-fill/checkerboard assignment still fails, so coverage and hue counts cannot masquerade as art direction. Motion/delivery-proof coverage must include a valid decoded Godot MJPEG packet and a negative case where an existing AVI without decoded/inspected visual artifacts is incorrectly claimed as watchback.

Record skill commit, Godot version, scenario ID, builder/reviewer contexts, requested scope, applicable composite cases, first-pass outcome, user-found defects, gate that should have caught each defect, false-positive burden, tokens/time, and whether the correction belongs in instructions, a template, a deterministic tool, or the game itself. Never tune the skill to one screenshot without a reusable failure mechanism.

Use `assets/forward-eval-matrix.template.json` and run `scripts/forward_eval_audit.py` once the suite is populated. A new gate is provisional until at least one positive and one negative fixture prove it changes behavior without blocking unrelated cases.
