## Runtime-size identity and typography

| Check | Evidence | PASS / FAIL / NOT TESTED |
|---|---|---|
| The title reads as a deliberate wordmark or authored typographic system, not merely a large default-font `Label` | | NOT TESTED |
| Lettering, scale, line breaks, spacing, material/effects, and placement remain intentional at actual runtime size | | NOT TESTED |
| The game mark/icon and title support one game-specific identity without becoming generic badge decoration | | NOT TESTED |
| The background/world treatment contributes to the identity instead of acting as an interchangeable dark/gradient backdrop | | NOT TESTED |

A bitmap wordmark is not mandatory. Native text is valid when font choice, lettering treatment, hierarchy, spacing, composition, and relation to the game's world are demonstrably authored. Plain oversized text in a common/default font does not become a wordmark merely because it is centered or capitalized.

Explicitly test whether the screen falls back to a reusable AI/template fingerprint: small badge or kicker, huge generic title, decorative accent line, redundant tagline, and a vertical stack of identical rectangular buttons over an interchangeable background. Any one device can be valid; the unexplained combination is not evidence of authored identity.
