# Blind composition calibration

Present the two SVGs at the same final size with neutral IDs, without filenames or this rationale. This is a diagnostic contrast, not a gold-standard production art benchmark. Both are original schematic examples and can be rendered by a browser or SVG renderer.

Ask the reviewer independently for each frame: what is being worked on, what action advances it, what state matters now, what the next purchase costs and changes, and which element should attract attention first. Preserve the initial answers before explanations.

After the first read, compare against `ui-design-workflow.md`. `clear-composition.svg` is the functional positive control: recognizable worked object, specific immediate action, 4/6 progress, 80-coin reward, and a 120-coin tool that doubles panels per action. Its plain text and rectangles are legitimate. `decorated-confusion.svg` is negative: equal competing actions, unspecified action effects, absent worked object, redundant headings, obscure upgrade consequence and marketing copy. Custom frames/colors do not repair these defects.

Do not award aesthetic excellence to either example. A reviewer should flag visible weaknesses even in the positive control. Add real licensed/viewable target-game references and actual production captures before using this as an artistic benchmark. This exercise calibrates action comprehension and hierarchy only.
